## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/domiciliation/telegram_emojis.git
```

Enter the directory:

```bash
cd telegram_emojis
```

Browse the folders and use the emoji images in your projects.

## 💻 Usage

Example in HTML:

```html
<img src="smileys_emotion/YOUR_EMOJI_FILE" alt="Telegram Emoji">
```

Example in Markdown:

```markdown
![Emoji](animals_nature/YOUR_EMOJI_FILE)
```

Replace `YOUR_EMOJI_FILE` with the filename of an image from the corresponding category.
